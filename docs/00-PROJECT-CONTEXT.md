# PalmPay体验设计Hub — Project Context

## 1. 项目名称

**PalmPay体验设计Hub / PalmPay Design Intelligence Hub**

## 2. 项目背景

该项目由 PalmPay 体验设计团队推动，目标不是建设一个作品集网站，也不是建设普通企业知识库，而是解决体验设计团队在 AI 时代面临的长期问题：

- 设计资产分散在 Figma、文档、聊天记录和个人文件中。
- 同类设计问题被重复研究、重复设计、重复沟通。
- AI 使用经验停留在个人 Prompt 和个人习惯中，难以复用。
- 团队缺少内容审核、版本、维护和失效机制。
- 设计工作的效率、质量和业务价值难以被持续衡量。
- 设计团队需要从“交付部门”升级为“体验增长与治理能力中心”。

## 3. 产品定位

PalmPay体验设计Hub 是一个面向体验设计团队的 **AI 驱动设计治理与能力复用平台**。

平台将：

- 设计资产
- AI Skill
- AI 实践案例
- AI 探索项目

沉淀为可发现、可使用、可维护、可审核、可衡量的组织能力。

一句话定位：

> 让设计经验从个人经验，变成可复用、可维护、可验证的团队能力。

## 4. 产品不是

- 设计师作品集
- 通用知识库
- Figma 替代品
- Jira 或完整项目管理系统
- 通用 AI 聊天机器人
- 一次性 CEO 汇报网站
- 只展示 AI 项目的门户

## 7. 核心用户

### 设计成员

目标：

- 查找设计资产
- 使用 AI Skill
- 收藏和复用内容
- 贡献规范、方法和案例
- 查看个人草稿、提交和待办

### 内容审核人

目标：

- 审核设计资产、AI Skill 和案例
- 保证内容完整性、可信度和可复用性
- 通过或退回内容
- 记录审核意见

### 平台管理员

目标：

- 管理用户、角色和团队
- 管理分类标签
- 管理内容状态
- 管理发布、下架和归档
- 查看审计和平台运行情况

### 设计管理者

目标：

- 查看真实复用情况
- 查看内容建设质量
- 识别团队能力缺口
- 查看 AI 使用和验证结果
- 决定下一阶段建设优先级

## 8. 核心产品闭环

平台最重要的闭环是：

> 团队产生经验  
> → 结构化沉淀  
> → 审核发布  
> → 被其他成员找到  
> → 在真实项目中使用  
> → 记录效果  
> → 形成新的案例和能力

V1.0 的所有功能优先级应围绕该闭环判断。

## 9. V1.0 重构目标

从静态交互原型升级为正式可运行产品，建立：

- 企业登录
- 用户与团队
- RBAC 权限
- 统一内容模型
- 内容版本
- 草稿与审核
- 发布与归档
- 文件存储
- 搜索
- 收藏与最近浏览
- 真实使用记录
- 行为事件
- 数据洞察
- 审计日志
- AI Gateway 接入边界
