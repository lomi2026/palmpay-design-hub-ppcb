# 全平台交互性能审查与统一方案（2026-09-16）

## 范围与证据

本轮以正式 Web 源码为主检查导航、Tab、筛选、详情、收藏、搜索、草稿、上传、发布、生命周期、管理表单、会话和缓存；并非所有线上业务流程的计时验收。已有线上菜单缓存验收；本轮详情仅本地验证：模拟 600ms 延迟，80ms 时首次为骨架、重复访问为缓存，最终 URL 与唯一可见内容区正确。构建、Lint 与 64 项测试通过。未执行线上写入或发布本轮详情改动。

## 当前整页缓存的优先修正项

1. **路由与展示内容绑定。** 缓存先展示时浏览器真实 pathname 尚未切换，ContentShareButton 的 usePathname 可能生成来源页面链接。应由内容传入 canonical URL，不从暂未提交的全局路由推导。
2. **缓存内容副作用。** 快照中的客户端组件会重新挂载；最近浏览刷新、数字动画等副作用需仅在真实目标激活时执行，避免缓存预展示与真实加载重复触发。客户端局部筛选状态不能仅依赖组件重新挂载后的默认值。
3. **精确失效。** 当前任何非 GET 表单提交都会清空所有快照，即使验证失败或只是自动保存。改为服务端确认成功后的内容 ID/资源类型级失效，同时用请求序号防止在途旧响应重新写回。
4. **失效内容保护。** 缓存 TTL 不是权限保证；保持后端鉴权、身份范围隔离、401/403/404处理。会话无法验证时不继续展示旧内容。编辑器未保存内容不能被后台新快照覆盖。
5. **布局保留。** 页面快照主要解决首次反馈，不能保证所有本地组件状态和焦点都保留；后续以数据缓存驱动稳定组件更新，减少整页替换。

## 统一交互规则

- 读操作：无缓存用局部骨架，有缓存立即显示，后台校准；不将未知数字显示为 0。
- 本地操作：Tab 外壳、折叠、排序等立即响应。
- 可逆轻写：收藏等允许乐观更新，必须可回滚。
- 关键写入：发布、删除、权限修改必须等待服务端确认；等待发生在操作按钮或相关区域，不能伪造成功。
- 错误：读取失败可保留仍有权限的旧内容；写入失败保留用户输入，不用成功提示掩盖未确认结果。
- 缓存隔离：账号、组织、权限、路径、筛选分页键；登出清空；限制容量和寿命。
- 竞态：只采纳最新请求，切换离开取消无用读取；重复提交受控，修改后失效优先于旧请求回写。

## 建议执行顺序与验收

P0：修复整页缓存路由、副作用及写入失效边界，再统一详情/Tab/GET 筛选入口。
P1：收藏局部乐观更新；管理行局部保存；发布后目标列表更新；附件区域更新。
P2：正文与辅助统计分区加载、数据库与序列请求分析、端到端耗时监测。

目标：点击反馈在约 100ms 内出现；缓存命中不闪骨架；不承诺后端请求在 100ms 内完成。分别记录点击到反馈、点击到可用内容、后台请求完成三项指标。验收覆盖快慢网络、连续快速切换、筛选分页、失败重试、会话过期、权限撤销、删除后返回、编辑途中刷新与移动端滚动。用隔离测试响应验证竞态，写操作测试使用可清理测试内容，不修改真实业务内容。

## 第一批实施（本地，2026-09-16）

- 五类详情、管理 Tab、收藏/浏览 Tab、六类目录/贡献 GET 筛选接入现有会话导航缓存。筛选保留 URL 参数，改为客户端导航，避免清空整个页面会话。
- 分享链接从具体内容 canonicalPath 生成；缓存快照不重播数字动画；最近浏览移除挂载后的重复刷新。
- 管理保存/发布成功后失效缓存，并通知其他标签页；自动保存成功仅失效工作台、贡献和发布入口。草稿预览因服务端直接跳转，仍在提交前保守失效相关页面；其他未迁移写表单继续保守清理。
- 加入失效代次检查，写入期间返回的旧导航结果需要重新校准；不可访问详情清除快照。
- 本批沿用整页快照，尚不是局部数据缓存：首次 Tab/筛选仍可能显示整页骨架。收藏乐观更新、管理行/附件局部更新、编辑离开保护、辅助统计分区加载及全流程线上计时仍待后续实施。

## 全量实施结果（2026-09-16，本地未发布；替代第一批剩余项）

| 问题组 | 本次实现 |
| --- | --- |
| 主菜单、卡片与返回链接 | 工作台内统一使用缓存感知链接；同页再次点击只刷新，不保留错误 pending；首次骨架、缓存立即显示、后台校准。编辑器仅提供加载外壳，不复用可写表单快照。 |
| Tab、分页与筛选 | 管理/收藏分区即时选中；页头与筛选控件保留，只替换 WorkspaceResults 区域。GET 筛选使用客户端导航，参数保留在 URL；项目组合的本地筛选也写入 URL，避免返回时丢失。 |
| 搜索与点击记录 | 搜索页接入导航和局部结果；结果点击直接打开详情，独立同源接口后台记录点击，统计失败不阻断打开。接口验证来源、身份和参数。 |
| 详情与辅助数字 | 正文不等待 usage-summary，五类详情独立请求辅助统计，按内容和身份范围缓存；失败可重试，未知值不显示 0。切换不同内容重建对应数字组件；快照不重播动画，不重复触发请求。 |
| 收藏 | 共享状态立即反馈、单内容防重、失败回滚和中文错误提示；服务端仅返回写入确认，不重定向或刷新整个布局。成功后相关缓存失效，其他标签页同步校准。 |
| 新建与进入编辑 | 新建确认后跳转，失败保留输入；编辑路由有独立外壳，待真实草稿返回才启用写入。新建页与编辑器均有未保存离开保护。 |
| 自动保存与预览 | 900ms 防抖与 React Action 顺序写入；用输入修订号判断哪次响应可标记“已保存”，防止旧响应误清新修改。预览保存独立 pending，成功才打开；失败保留输入。 |
| 管理保存 | 普通 PATCH 行返回确认/规范化字段后原位更新，不读整页；结构或权限变化在确认后后台校准。保存和校准期间保护当前行，完成后恢复焦点；未保存离开提醒。 |
| 发布 | 一次提交最新表单，服务端确认后返回真实标题/摘要和目录地址；过渡期展示发布回执，目录及数字后台刷新。发布/预览/删除防重，上传处理中禁止发布，允许继续编辑文字。 |
| 删除、下架、归档 | 后端状态确认后才移除或跳转；贡献/管理列表删除立即移除目标行，再后台校准数量。保留既有权限与确认规则。 |
| 封面与附件 | 使用签名地址直传，真实上传进度，校验/绑定状态分开；局部更新文件区域，不刷新编辑器；失败保留选择并重试。已传输文件的绑定重试复用 fileId，READY 完成确认幂等。 |
| 附件并发 | 新增按单文件添加/移除的认证接口，事务检查草稿状态、组织和文件管理权限；不再用客户端旧附件列表覆盖其他上传。无需数据库迁移。 |
| 下载与复制 | 下载只锁定当前按钮，继续服务端授权；不因读表单清理页面缓存。复制采用内容 canonical URL，记录不影响复制反馈。 |
| 最近浏览、使用确认、关联与通知 | 最近浏览不再挂载后重复刷新；使用/关联表单给出局部 pending、错误和成功确认；通知已读操作先返回确认再校准数量。 |
| 缓存与失败边界 | 保留账号/组织/权限隔离、容量/寿命限制；修改失效代次优先于在途旧导航；404/403详情不复用旧快照；跨标签页通知失效。关键发布/删除/权限操作仍保守清理较大范围，自动保存和收藏采用定向范围。 |
| 后台与监测 | 已授权详情的附件读取和浏览记录并行；搜索记录、结果读取及独立事件并行。浏览器 User Timing 记录 workspace:feedback / cached-content / fresh-content，最多保留有限条目；可用 PERFORMANCE_TRACE=1 记录 Web→API 耗时，省略参数、正文和凭证。 |

### 验收与界限

前后端生产构建、Lint、Web 68 项测试以及相关 API 26 项回归通过。测试包含收藏确认/失败、发布回执、搜索点击来源校验、附件权限/并发绑定/完成幂等、发布状态及内容权限。

本地浏览器模拟 600ms 延迟验证首次/重复详情、局部 Tab、筛选保留文档、快速连续菜单、收藏 80ms 反馈及断网回滚；断网导航保留当前页并提示重试，恢复网络后可以继续跳转；临时内容验证自动保存、离开保护、上传不重载且保留文字、真实发布后目录更新及删除；临时团队验证保存持久化、文档与焦点保留。测试数据已清理。390px 无横向溢出，截图已查看。

测得若干导航反馈约 3–15ms，一次管理 Tab 新数据约 624ms；这些是本地模拟慢网样本，不是线上性能承诺。只读 EXPLAIN ANALYZE 的本地目录与计数查询约 0.131ms / 0.084ms，未发现需要新增索引的证据；未改数据库结构。上线后的真实地域网络、托管休眠、生产负载与数据库查询计划仍需部署后复测，不能用本地结果替代。保留现有服务端鉴权和真实统计，不以动画或假数字伪造接口完成。
