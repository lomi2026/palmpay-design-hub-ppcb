# 工作台间距规范

两套工作台主题共用 `apps/web/src/app/workspace-spacing.css`。

| 层级 | 桌面 | 手机 |
| --- | --- | --- |
| 页面左右及顶部边距 | 32px | 16px |
| 主要模块间距 | 24px | 16–24px |
| 卡片内边距 | 24px | 16px |
| 同组卡片、分栏字段间隔 | 16px | 16px |
| 表单字段之间 | 24px | 16px |
| 标签与内容 | 8px | 8px |
| 同组按钮、控件 | 8–12px | 8–12px |
| 页面底部留白 | 48px | 32px |

新增页面优先复用页面头部、筛选栏、详情章节和编辑器组件。紧凑操作组不使用模块级间距；长文本使用行高控制可读性。分页、空状态和帮助说明跟随所属模块，不额外叠加重复外边距。
