# 全平台圆角规范

2026-09-16，根据用户要求完成现有正式前端组件及页面样式梳理。

## 原有问题

固定圆角混用 4、6、8、9、10、12、13、14、16、18、20、22、24、26、28、32、36px，以及全圆角；公共组件、页面局部样式、主题覆盖各自定义。工作台统计卡片的 focus-visible 曾将圆角改为 4px。部分小按钮随尺寸变体改变圆角。

## 统一规范

| 分类 | 圆角 | 组件 |
| --- | --- | --- |
| 小型元素 | 8px | Tab、菜单选项、提示浮层、小型矩形标签 |
| 操作与表单 | 12px | 主次按钮、图标按钮、输入框、文本域、选择器、侧栏菜单项 |
| 普通表面 | 16px | 内容卡片、统计卡片、工作台入口卡片、下拉面板 |
| 大型表面 | 24px | 页面主视觉卡片、分区面板、弹窗、编辑区 |
| 形状例外 | 圆形或胶囊 | 头像、状态圆点、状态徽标、进度条；普通操作按钮不用胶囊 |

所有尺寸按钮圆角保持 12px；管理导航 Tab 保持此前约定的 8px。卡片内图像裁切和覆盖链接继承容器边界。线形 Tab 容器保留直角；贴边抽屉的结构边界由布局决定。

## 状态规则

默认、悬浮、按下、选中、展开、键盘焦点、只读、禁用、错误、提交中均保持组件基础圆角。状态通过背景、描边、焦点轮廓和透明度表达，不改变形状。亮暗主题及响应式断点使用同一圆角值。

## 实现

`component-radius.css` 定义四档语义变量并统一公共组件；原有 CSS/TSX 中非规范固定圆角已归并到上述档位。`globals.css` 中 Tailwind 圆角变量同步为明确数值。保留非交互装饰圆形，不改变数据、权限和业务交互。
